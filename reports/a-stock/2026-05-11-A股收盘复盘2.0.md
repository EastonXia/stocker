## 6. 板块轮动分析

**TOP 3 重合度判定:延续(>2/3)。** 5 月 8 日(上周五)A 股领涨即为半导体 / 元件 / 通信设备链,今日 TOP 3 仍是稀土、半导体设备、半导体材料,**核心成长主线未切换,半导体维持周内主线地位**;但内部细分有切换——上周五偏元件 / PCB / CPO,今日切到设备 + 材料 + 存储,体现资金在半导体大类内部由"应用 + 互联"向"上游卡脖子"轮动。

**资金迁徙路线:** 防御 → 进攻、周期 → 成长、大盘 → 小盘。具体表现为:
- **从黄金 / 航运 / 钾肥 / 食品饮料 → 半导体 / 稀土 / 疫苗**:典型的"避险退、风险接管"切换;
- **从大盘蓝筹 → 中小盘成长**:科创 50 +4.65% 远超上证 +1.08%,说明增量资金集中流向科技小盘。

**高低切信号:不明显但存在端倪。** 真正的"高低切"是高位连板炸板、低位超跌反弹,而今日:
- 高位股(沃格光电 zbc=34、博敏电子 zbc=23、远东股份 zbc=27)虽然反复但**最终封死**,**未发生集体退潮**;
- 低位超跌反弹方向不显著,反而是"主线 + 题材"齐升;
- **结论:今日是主线扩散日,而非高低切日**。

**风格定位:成长 + 题材双驱**。当前市场风险偏好处于近 30 日高点,成长 / 高弹性板块全面强于价值 / 防御板块。这种格局通常持续 3-5 个交易日后,会在某个外部催化(美股大跌 / 政策真空 / 量能萎缩)下出现首次松动。
